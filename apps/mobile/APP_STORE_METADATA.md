## Description
A fun and colorful Sudoku puzzle game designed for kids! Instead of numbers, players use cute fruit emojis to solve puzzles.

FEATURES:
- Three difficulty levels: Easy (4x4), Medium (6x6), and Hard (9x9)
- Beautiful fruit emoji pieces — apples, bananas, grapes, and more!
- Sound effects and haptic feedback for every move
- Hint system on Easy mode to help beginners learn
- Friendly error system — mistakes show sad faces that disappear after 30 seconds
- Checkmarks show which fruits are fully placed
- Flashing animations when you complete a row, column, or box
- "How to Play" guide built right in
- No ads, no accounts, no in-app purchases — just play!

PERFECT FOR:
- Kids ages 4-10 learning logic and problem-solving
- Young learners new to Sudoku
- Parents looking for a safe, ad-free game for their children
- Classroom use and educational settings

HOW TO PLAY:
1. Tap a fruit button to pick it up
2. Tap an empty cell to place it
3. Each row, column, and box must have every fruit exactly once
4. Be careful — 5 mistakes and it's game over!
